# YR-deep-learning-demo

Interactive classroom webpage that teaches deep learning fundamentals:

- Interactive network diagram (inputs, outputs, nodes, weights, biases, layers)
- Hands-on single-neuron calculator
- How depth builds representations
- Six-concept recap

## Run it

Open `index.html` in any browser. No build step, no dependencies — the page is a single self-contained file.

## Live demo

A hosted copy of this page is available at https://muse.ai/s/deep-learning-network-xvxg6ixyrxe6xtgxt
